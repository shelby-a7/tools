# Development Resources

Guides and templates for project development.

## Contents

- **[AI Development Reference](ai-development-reference.md)** — Portable context document for any contributor or agent continuing development of a project. Covers requirements traceability, build process, development steps, QA records, environment setup, and handoff procedures.
- **[Tracking Plan Template](tracking-plan-template.md)** — Tool-agnostic template for product analytics implementation plans. Covers SDK setup, event taxonomy (page views, clicks, identity, subscriptions, engagement, user properties), phased rollout, QA checklists, and architecture reference. Designed for SaaS/PLG apps with a client + server SDK architecture.
