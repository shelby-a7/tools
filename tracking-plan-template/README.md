# Tracking Plan Template

Tool-agnostic template for product analytics implementation plans. Derived from a PostHog implementation on a Next.js web application.

## Contents

- **[tracking-plan-template.md](tracking-plan-template.md)** — The tracking plan template. Covers SDK setup, event taxonomy (user registration, product engagement, subscriptions, user properties, page views, button clicks, modal lifecycle), phased rollout, QA checklists, and architecture reference. Designed for SaaS/PLG apps with a client + server SDK architecture.

## Usage

Copy `tracking-plan-template.md` into your project and replace the `{PLACEHOLDER}` values with your application's specifics. See the template's customization instructions for details.
